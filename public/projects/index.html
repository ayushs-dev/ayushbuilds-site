AAQR — Autonomous Air Quality Rover

A Roomba-based robot that navigates waypoints with ROS 2 and Nav2, pauses at each stop, and streams air quality readings from a Raspberry Pi sensor node to a Flask server with a live dashboard. Built in 2023–24 across two repos, now consolidated into one documented project.

GitHub Repo Analyzer

Type any public repo as owner/repo and get its stars, forks, language breakdown and top contributors. A FastAPI backend caches GitHub results in PostgreSQL for an hour, a React frontend renders them, and a single docker compose command runs the whole stack.
